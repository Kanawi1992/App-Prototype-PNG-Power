# PNG Power Limited - Digital Portal Application (v4 - Multi-Page SPA)

This package contains the complete, self-contained single-page application (SPA) for the **PNG Power Limited Customer Digital Portal**.

## Package Contents
- `index.html`: The complete web application containing multi-view SPA navigation, Tailwind CSS styles, SVG branding, EasiPay buying guides (`*775#`, `*776#`, `*131#`, `*888#`), Regional Grid Information, News & Notices feed, Office Finder directory, Confidential Fraud Reporting hub, Safety & Outages ticket generator, and the interactive PPL Virtual Assistant chatbot.
- `README.md`: Setup and deployment instructions.

## How to Run / Test Locally
1. Unzip `png_power_app_package-v4.zip`.
2. Double-click `index.html` to open it directly in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox, or Brave).
3. No build tools or backend server installation required. Can be copied directly to an external SD card for offline local mobile access.
